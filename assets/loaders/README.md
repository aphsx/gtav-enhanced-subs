# Loaders (not vendored)

This folder intentionally does **not** contain `OpenRPF.asi` or ASI-loader DLLs.

Download loaders from their upstream projects (see repo root `THIRD_PARTY.md`), then place them in your **game directory** yourself when installing a locally built pack.

`args.txt` may be copied if present; it is a tiny launch helper, not a game binary.
