# Font asset

`font_lib_efigs_pc.gfx` — Thai glyph atlas for Enhanced Scaleform.

- Required to show Thai (otherwise tofu □)
- Same lineage as common Thai FONTONLY / community efigs packs
- See root `NOTICE.md` before redistributing widely

Builders: keep this file in `assets/` so `tools/build.py --install` can inject it into your stock `scaleform_platform_pc.rpf` (does not ship a full game RPF).
