# Third-party components

## Included in this repository

### Sarabun (font)
- Files: `assets/fonts/Sarabun-Regular-GTA.ttf`, `assets/OFL-Sarabun.txt`
- Upstream: [google/fonts ofl/sarabun](https://github.com/google/fonts/tree/main/ofl/sarabun)
- License: **SIL Open Font License 1.1**
- Note: `Sarabun-Regular-GTA.ttf` adjusts tone-mark glyph metrics for Scaleform; still OFL.

### rpfpeek (not vendored)
- Used as a Python dependency (`requirements.txt`)
- Users install separately; follow that project’s license

## Not included — obtain yourself (do not commit binaries here)

### Mods folder loader (Enhanced)
Choose one **official upstream** download (do not re-upload their ASI into this repo):

- Community loader listings such as [OpenRPF on GTA5-Mods](https://www.gta5-mods.com/tools/openrpf-openiv-asi-for-gta-v-enhanced) (third-party; check their page for terms), **or**
- Open-source alternative **RageOpenV** — [GitHub releases](https://github.com/Chiheb-Bacha/RageOpenV) (GPL-3.0; their README asks not to redistribute binaries — link only)

### ASI loader DLL
- e.g. [Ultimate ASI Loader](https://github.com/ThirteenAG/Ultimate-ASI-Loader) — follow that project’s license / releases

### JPEXS FFDec (font rebuild optional)
- [jindrapetrik/jpexs-decompiler](https://github.com/jindrapetrik/jpexs-decompiler) — used only if you rebuild fonts locally
